# Локальная мультиагентная система финансового ИИ-аудита (LLM-as-a-Judge)

Инженерный проект по созданию автоматизированного контура валидации макроэкономических данных и фактчекинга языковых моделей. Система построена на базе подхода **LLM-as-a-Judge**, где тяжелая нейросеть выступает строгим «судьей» для выявления логических ошибок, подмены понятий и «галлюцинаций» в финансовых текстах.

## 🛠️ Архитектура и аппаратное обеспечение
Проект развернут полностью локально на ПК (NVIDIA 8GB VRAM, 64GB RAM) с использованием двух параллельных ИИ-движков:
1. **Генератор базового ответа:** модель **Qwen 3.5 (9B)**, запущенная через локальный сервер **Ollama** (температура 0.7 для беглого и развернутого ответа).
2. **Старший финансовый аудитор:** тяжелая интеллектуальная модель **Qwen 3.8 (27B) Reflect**, запущенная через сервер **LM Studio** (температура 0.1 для максимальной строгости, логики и детерминированности).

Связующий мост между движками написан на чистом Python с использованием стандартной библиотеки `urllib`, что полностью исключает конфликты сетевых кодировок при передаче кириллицы.

## 📈 Пример реального кейса: Разгром поверхностной логики ИИ
Моделям был отправлен сложный стресс-сценарий: *«Влияние повышения ключевой ставки ЦБ РФ с 16% до 21% и одновременного роста мировых цен на золото на компанию с плавающим рублевым долгом в 10 млрд руб.»*.

### Результаты аудита моделью Qwen 27b Reflect:
Тяжелая модель провела построчный разбор и выявила грубые методологические галлюцинации младшей модели:
* **Грубая ошибка учета EBITDA:** Младшая модель ошибочно вычла процентные расходы из операционного показателя EBITDA.
* **Инверсия валютного риска:** Модель запуталась в базовом экономическом эффекте, заявив, что при укреплении рубля стоимость импортного оборудования вырастет (в реальности сильный рубль удешевляет импорт).
* **Подмена макроэкономической логики:** Модель утверждала, что высокая ставка ЦБ вызывает «отток капитала» (в реальности она привлекает капитал в высокодоходные рублевые инструменты).
* **Игнорирование налогового щита:** Младшая модель не учла эффект снижения налога на прибыль за счет роста процентных расходов.

Полный текст глубокого аналитического вердикта старшей модели сохранен в файле `polyus_result.txt`.

## 🚀 Как запустить проект локально
1. Запустите Ollama с моделью Qwen 3.5.
2. Запустите LM Studio в режиме Local Server с моделью Qwen 3.8.
3. Выполните команду в терминале:
   ```bash
   python ai_audit.py
   ```
