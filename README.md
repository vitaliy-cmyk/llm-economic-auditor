# Локальная мультиагентная система финансового ИИ-аудита

Инженерный проект по созданию автоматизированного контура валидации макроэкономических данных, корпоративной отчетности и фактчекинга языковых моделей. Система построена на базе подхода **LLM-as-a-Judge** и работает полностью локально, гарантируя 100% конфиденциальность обрабатываемых финансовых данных.

---

## 🛠️ Аппаратное обеспечение (Hardware Stack)
Система оптимизирована для работы на одном рабочем месте без использования облачных API:
* **Вычислительный узел (GPU):** NVIDIA GPU с **8 ГБ VRAM** (выделена под инференс квантованных LLM).
* **Оперативная память (RAM):** **64 ГБ RAM** (обеспечивает удержание контекста, работу движков и фоновую потоковую обработку данных).

---

## 🏗️ Программная архитектура и ИИ-движки
Связующий мост между движками написан на чистом Python с использованием библиотеки `urllib`, что полностью исключает конфликты сетевых кодировок при передаче кириллицы. Оркестрация распределена между двумя изолированными серверами:

1. **Младший аналитический модуль:** модель **Qwen 3.5 (9B)**, развернутая через сервер **Ollama** (порт `:11434`, температура 0.7 для генерации беглых, развернутых ответов и экспресс-фильтрации).
2. **Старший финансовый аудитор (Судья):** тяжелая интеллектуальная модель **Qwen 3.8 (27B) Reflect**, развернутая через сервер **LM Studio** (порт `:1234`, квантование *Q5_K_XL*, температура 0.1 для максимальной строгости, логики и детерминированности).

---

## 🎯 Функциональные модули (Кейсы применения)

Система разделена на два независимых конвейера обработки информации.

### КЕЙС №1. Конвейер автоматизированного парсинга и генерации тепловых карт рисков (Pipeline: PDF ➔ JSON ➔ Excel)
Модуль предназначен для пакетного анализа официальной раскрываемой отчетности крупного бизнеса (МСФО, ESG, Годовые отчеты).

* **Шаг 1 (`extract_mda.py`):** Извлечение сырого текста из объемных файлов `polyus_2025.pdf` и `seligdar_2025.pdf` с помощью библиотеки `pdfplumber`.
* **Шаг 2 (`ai_matrix.py`):** Пакетная отправка текста в модель-судья (LM Studio). Реализовано жесткое посимвольное ограничение контекстного окна (до 15,000 символов) для предотвращения ошибок переполнения (HTTP 400). Модель осуществляет классификацию финансовых рисков и возвращает строго очищенный, валидный **JSON**.
* **Шаг 3 (`make_excel.py`):** Парсинг JSON-ответов средствами `Pandas` и генерация финальной цветной тепловой карты рисков в формате Excel (`financial_risk_heatmap.xlsx`) с использованием стилизации `openpyxl`.

### КЕЙС №2. Кросс-валидация и разгром поверхностной логики ИИ (Паттерн: LLM-as-a-Judge)
Модуль предназначен для фактчекинга, выявления скрытых логических ошибок, подмены понятий и «галлюцинаций» в экспертных финансовых текстах.

**Сценарий стресс-тестирования:** Моделям отправлен сложный макроэкономический запрос: *«Влияние повышения ключевой ставки ЦБ РФ с 16% до 21% и одновременного роста мировых цен на золото на компанию с плавающим рублевым долгом в 10 млрд руб.»*.

* **Действие Ollama (9B):** Сгенерировала быстрый, поверхностный финансовый обзор сценария.
* **Действие LM Studio (27B Reflect):** Провела построчный аудит ответа младшей модели и выявила грубые методологические ошибки:
  * *Ошибка учета EBITDA:* Младшая модель ошибочно вычла процентные расходы из операционного показателя EBITDA.
  * *Инверсия валютного риска:* Модель заявила, что при укреплении рубля стоимость импортного оборудования вырастет (в реальности сильный рубль удешевляет импорт).
  * *Подмена макроэкономической логики:* Модель утверждала, что высокая ставка ЦБ вызывает «отток капитала» (в реальности она привлекает капитал в высокодоходные рублевые инструменты).
  * *Игнорирование налогового щита:* Младшая модель не учла эффект снижения налога на прибыль за счет роста процентных расходов.

Полный текст глубокого аналитического вердикта старшей модели сохранен в файле `polyus_result.txt`.

## 🚀 Инструкция по локальному запуску

1. Запустите сервер **Ollama** с моделью `Qwen 3.5`.
2. Запустите сервер **LM Studio** в режиме Local Server с моделью `Qwen 3.8`.
3. Для запуска **Кейса №1** (Анализ отчетов и сбор Excel):
   ```bash
   python extract_mda.py && python ai_matrix.py && python make_excel.py
   ```
4. Для запуска **Кейса №2** (Интерактивный аудит и фактчекинг):
   ```bash
   python ai_audit.py
   ```
